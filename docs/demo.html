    What these numbers drive

    The three decisions the tool exists to support:

    1 · Spot a stalled or failed sample → the attention list, and the "Stalled / QC failures" views in the graph.

    2 · Trace one sample's provenance → click a node in the graph, or the search box, then "Trace to origin / results".

    3 · Judge pipeline health → this funnel, QC-by-type, and turnaround, filterable by study / sample type.

    Sample workflow — where specimens are in the process

    The pipeline schema. Each real specimen is an instance traversing it; the count is how many have reached each stage.

    Branch point — AllPrep (extraction). One specimen splits into DNA, RNA and Protein fractions that are QC'd separately and travel to different platforms. A specimen can therefore be complete for DNA and stalled for RNA at the same time — which is why the model is a graph, not a line.
